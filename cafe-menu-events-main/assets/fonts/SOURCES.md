# Self-hosted fonts

Markazi Text and Rakkas are from the official Google Fonts repository; Noto Nastaliq Urdu is the existing project font. All retain their adjacent SIL Open Font License notices.

- https://github.com/google/fonts/tree/main/ofl/markazitext
- https://github.com/google/fonts/tree/main/ofl/rakkas

WOFF2 copies preserve Arabic/Persian shaping features, Latin labels, punctuation and the original variable weight ranges. Original TTF sources are retained for reference; pages request WOFF2 only.
